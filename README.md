# Design Templates Library

A reference library of website designs and styles for reuse when building new projects.

## Structure

```
design_templates/
├── README.md              ← this file
├── _template.md           ← copy this when adding a new entry
└── designs/
    └── [design-name].md   ← one file per design reference
```

## How to use

When starting a new project, describe what you want to build and ask Claude to pull relevant entries from `designs/`. Each entry is self-contained and structured for LLM consumption.
